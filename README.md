# Nurse Shift Mobile Web

เว็บแอปสำหรับใช้งานบนมือถือเพื่อจัดตารางเวรพยาบาล สร้างคำสั่ง OT เวรสแปล และสรุปเวรรายเดือนจากข้อมูลชุดเดียว

## ความสามารถ

- เลือกเดือน/ปี พ.ศ.
- สร้างเดือนใหม่
- อัปโหลด Excel ตารางเวรแบบ ชื่อ | 1 | 2 | ... | 31
- แก้เวรบนมือถือด้วยการแตะช่องเวร
- รองรับรหัส ช, บ, ด, 0, Va, SL, PL, PH
- คัดลอกจากเดือนก่อน
- ตรวจ conflict เบื้องต้น เช่น เวรดึกต่อเวรเช้า และวันที่ไม่มีเวรครบ
- Export DOCX: คำสั่ง OT, เวรสแปล, สรุปเวร
- Export XLSX: ตารางเวร, สรุปเวร
- Print/Save as PDF ผ่านเมนูพิมพ์ของเครื่อง
- สำรอง/กู้คืนข้อมูลเป็น JSON

## วิธีรันบนเครื่อง

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000`

## Deploy บน Vercel

```bash
npm install
npm run build
npx vercel deploy --prod
```

ต้อง login Vercel หรือใช้ VERCEL_TOKEN ก่อน deploy

## หมายเหตุ

เวอร์ชันนี้เป็น MVP สำหรับมือถือ เก็บข้อมูลใน localStorage ของเบราว์เซอร์ ถ้าต้องใช้หลายเครื่องพร้อมกันควรต่อฐานข้อมูล Supabase/PostgreSQL เพิ่มในรุ่นถัดไป
